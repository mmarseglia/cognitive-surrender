# Defensive Prompts

Each file below is a prompt and nothing else. Copy the whole file into any of these:

- **Every conversation** — Claude's Settings → Personalization.
- **One Project** — the Project's instructions.
- **One chat** — paste it as your first message.
- **Claude Code** — paste it into a `CLAUDE.md`, or include the file from one.

If you write code daily, install the coding prompt first. If your AI use is mostly outside code, start with the general prompt. Specialized prompts stack on top of the general prompt — they do not replace it. Keep a specialized prompt out of Settings → Personalization: put it in a Project, a chat, or a `CLAUDE.md`, where it applies only to that work.
